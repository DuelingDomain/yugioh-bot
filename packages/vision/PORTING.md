# Duel Lens port inventory

Audit source: [mathulbrich/duel-lens](https://github.com/mathulbrich/duel-lens/tree/f6968f3682d53a79c4a9fef591300615eda61c11), commit **`f6968f3682d53a79c4a9fef591300615eda61c11`**, inspected 2026-11-01. Source was read from a temporary pinned clone; no upstream script, installer, trainer or harvester was executed. Apache-2.0 attribution is retained in source headers, `src/licenses/duel-lens.LICENSE`, `src/licenses/duel-lens.THIRD_PARTY_NOTICES.md` and repository `NOTICE`.

This is a source/feature inventory, not a claim of equal recognition accuracy. **Ported** means the numerical/source module is retained with at most local imports/types; **adapted** means the behavior or workflow is retained with material application changes, with omissions stated; **not ported** means no equivalent currently exists or the feature is intentionally excluded. Implemented round-2 UI/API statuses were confirmed by the implementing agent and checked against source. Helper-only work is explicitly identified; final app/browser verification belongs to the round-2 report. A module being adapted does not imply all upstream subfeatures were retained.

All target paths are relative to the repository root. `—` means intentionally no target. The runtime table lists every non-test module under upstream `src/` individually (115 files), including its build-only support modules. Relay runtime files and every non-test tool source are listed separately. Tests, declarations, assets and documentation scopes are explicitly accounted for below; no entire upstream folder is implied to have been ported.

## Recognition and interaction feature matrix

| Feature | Status | Implementation, boundary and reason |
| --- | --- | --- |
| Detector, projective straighten, art crop, ONNX embedding, cosine index | adapted | `packages/vision/src/detector/` and `src/{geometry,hypotheses,embed,pipeline,search}.ts`; generic profiles, Worker API and native-pixel camera/photo input. |
| All-card gold freeze outlines | adapted | `packages/vision/src/{client,worker,pipeline}.ts` and `packages/web/app/dev/vision-lab/` expose detect-all on one frozen camera/photo snapshot, ordered gold SVG outlines and Resume. Face-down quads deliberately remain visible, unlike upstream. Detect-all differs from “Read all cards,” which also recognizes/groups cards by player. |
| Quad selection and overlap hit testing | adapted | `packages/vision/src/scene.ts` selects the actual normalized detected polygon after contain-letterbox mapping. Smallest-area winner; within 10% area, area-normalized center distance. Upstream oriented-box padding is adapted to a 24 CSS-px minimum target after exact polygon hits, so expanded targets never steal a direct hit. |
| Dismissible candidate popover | adapted | `packages/web/app/dev/vision-lab/vision-lab.tsx` anchors/clamps candidates and supports outside/Escape dismissal with focus restoration. Complete upstream text/banlist/Genesys/copy/pinning/reporting are omitted. |
| Keyboard model | adapted | Tab/Enter activate outlines; number/arrow keys choose candidates; Escape closes popover and focus returns. Native form controls retain keys. Upstream playback shortcuts, copy/keep/read-board/find accelerators and extension focus-trap behavior are not copied wholesale. |
| Confidence tiers | adapted | `search.ts` returns `sure`, `not sure`, `low match`; visual score/lead/card-back margins determine certainty; fallback and ambiguous views remain uncertain, priors cannot promote. Upstream rescue/suggestions/covered semantics and thresholds are not identical. Similarity is not a probability. |
| Upside-down/opponent and defense-position cards | adapted | `hypotheses.ts` retains upright/180° and 90°/270° user-box variants; detector normalizes portrait quads. Upstream `layout-check.ts` first-rotation heuristic is omitted, so no brightness-grid ordering optimization. |
| Card back and placeholder artwork | adapted | Reserved profile card-back ID/vector, face-down whole-card hypotheses, separate score lead; `placeholder-art.ts` removes downloaded artwork that is actually the back. Detector face-down class alone never proves a back. |
| Pendulum art box | adapted | Upstream defines `ART_BOX_PENDULUM` but explicitly does not use it at runtime: documented 13/14 correct standard-box top-1 versus 9/14 pendulum-box on its small study. Local runtime keeps standard `artWindow`; trainer metadata includes optional pendulum window. This is not a missing runtime feature. |
| Cards cut at image boundary / truncation | adapted | `truncation.ts` retains seen mask/share, whole-card bilinear warp, profile-art-window neutral fill, true-edge margin helpers and selective padding. `pipeline.ts` uses the masked warp, fills unseen pixels with art mean and prevents sure when corners extend outside or seen share is below .995. 8 helper tests pass. Upstream padded redetection and separately calibrated rescue acceptance remain absent. |
| Partly covered cards / occlusion | adapted | `packages/vision/src/board.ts` retains `COVERED` bounds-fit thresholds; `pipeline.ts` adds conservative polygon-overlap suppression for exact outlined targets, including weak detections (.2–.4) and the 448px close-up fallback. Exposed through outline/result/peek/board `covered` flags; suggestions retained, `sure` suppressed. Depth is unknown, so both overlapping cards may be capped; missing/hand occlusions and nearly duplicate stacks remain limitations. No hidden-art reconstruction or upstream calibration claim. |
| Simulator pile-count badge removal | not ported | Upstream fallback detects white central digits and inpaints only after normal/rescue failure; simulator-specific and excluded from physical-camera path. No general inpainting claim. |
| Full-art/overframe layout and whole-card index | adapted | `packages/vision/src/full-art.ts`, `scripts/vision/build-full-art.ts`, `scripts/vision/full-art-prints.json` and `pipeline.ts` implement a separate validated whole-card index, layout hint and per-index matching. **Zero verified real full-art references currently exist in the manifest.** Synthetic actual-pipeline probes reported 9/9 with dedicated references versus 6/9 without; heuristic fired on 2/3 layouts (6/9 rotated cases). These are synthetic probes, not physical/full-art print accuracy. Upstream has no independent full-art reference index. |
| Optional AI | adapted | `client.ts` askAI and lab Ask AI use explicit owner/env-gated server route/client, bounded selected-card JPEG, four-second deadline, per-user rate limit and exact catalog resolution. Upstream extension BYOK and automatic AI fallback are intentionally replaced; tests mock HTTP. |
| Hover/focus peek | adapted | `createRecognizer().peek` returns best local name/tier without crop, history or AI. `use-outline-reads.ts` adds a 250ms dwell, snapshot cache, hoverable compact tooltip, focus access, Escape dismissal and stale-result cleanup. Placement is clamped beside the card; upstream facts/chips and overlap-cost placement are omitted. |
| Whole-board recognition and near/far assignment | adapted | `createRecognizer().readAll` detects once or uses same-frame outlines, reads up to 60 sequentially, groups normalized centers at y > .5 near / otherwise far, retains uncertain/error/face-down slots, and supports worker cancellation. Lab chooses side and seat for a session-only board twin; extension session storage, side panel and remote-room persistence are omitted. |
| Local correction/export | adapted | Current lab records selected IDs, guess, tier and sharpness in session JSON; upstream persists image crops + top-five for retraining. |
| Synthetic training | adapted | Seven embedding + seven detector Python files retained and input adapter added. Syntax/input preparation checked previously; no CPU retraining/export accuracy claim. Detailed module list below. |

## Deliberate scope and validation boundaries

1. The adapted masked warp now preserves whole-card geometry, fills unseen pixels neutrally and keeps partial hypotheses uncertain. Padded edge redetection is not wired into inference because its upstream rescue thresholds depend on selection-margin and private-footage calibration: it should run only when card extent reaches an actual frame edge; crop edges alone are insufficient. The internal seen mask/share measures samples inside source pixels and does not detect a hand covering pixels within the image. Public quality currently exposes a partial flag, not the full mask/share.
2. Upstream `COVERED` is calibrated for dragged rectangles. The exact-outline adaptation retains its competing-pick bounds-fit check and adds polygon overlap evidence; it caps confidence without reconstructing hidden artwork. Weak peaks are retained for scene evidence, and duplicate outlines are excluded at polygon IoU >= .8. Stacking order and hands cannot be reliably inferred. The synthetic overlap checks do not establish equivalence to upstream real-footage calibration.
3. Hover/focus peeks and read-all now have public API and lab consumers. Work stays local, sequential and cancellable; caches bind to one frozen snapshot and are cleared on thaw/source/backend reset. Read-all retains uncertainty and face-down/error slots. Near/far midpoint grouping is appropriate for one camera frame, not arbitrary multi-video layouts. Seat twins remain local lab state.
4. Upstream orientation evidence is a game-specific brightness heuristic; the lab retains both rotations and does not use that optimization on unknown/full-art layouts.
5. Keep exact full-art reference provenance/coverage separate from standard framed-card availability. Catalog inclusion, a full render URL, standard art crops and synthetic foil/overframe augmentation do not prove that a real full-art print was indexed.

Round-2 plan review (`docs/superpowers/plans/2026-11-01-remote-vision-round2.md`): the high-level architecture is consistent with these boundaries. Its acceptance checks should explicitly cover image/detection generation binding and stale request cancellation on thaw/source/backend changes; contain-letterbox/DPR mapping; overlapping and tiny outline targets; face-down handling; reading order and keyboard focus restoration/form-key preservation; absent/invalid full-art references and index-identity mismatch; AI owner/env/body/deadline/rate-limit/catalog guards; and separate synthetic versus held-out physical-photo evidence. These details are review recommendations, not claims that the current tests pass them.
